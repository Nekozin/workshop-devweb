## 📖 Sobre o Projeto

O **Workshop Carreira Digital** foi concebido com o propósito de aproximar estudantes do **3º ano do Ensino Médio** do universo da Tecnologia da Informação (TI).

A proposta uniu teoria introdutória de carreira tech com prática imersiva de desenvolvimento front-end, desmistificando o código e provando que qualquer estudante pode criar suas próprias páginas na web.

---

## 💡 Contexto & Desafio Superado

* **Instituição Parceira:** Externato José Bonifácio.
* **Programa:** Conectados pela Comunidade.
* **Desafio Identificado:** A escola não possuía um laboratório de informática tradicional com computadores desktop para a realização da oficina prática.
* **A Solução:** Adaptamos a oficina para utilizar um lote de **tablets da própria escola** que se encontrava subutilizado, além dos smartphones dos próprios alunos.
* **Abordagem Cloud:** Utilizamos a plataforma online **CodePen**, dispensando a instalação de editores pesados ou configuração local de ambiente.

---

## 🛠️ Metodologia & Ferramental

A dinâmica da oficina foi dividida em duas frentes complementares:

1. **Frente Educacional:**
   - Introdução à lógica de estruturação e estilo na web (Tags HTML semânticas e Seletores/Propriedades CSS).
   - Prática direta no navegador com renderização em tempo real via CodePen.
   - Cada aluno desenvolveu uma página autoral sobre um tema de seu interesse pessoal.

2. **Frente Técnica (Este Repositório):**
   - Criação de uma landing page centralizadora com carrossel interativo.
   - Indexação e preservação dos trabalhos desenvolvidos pelos alunos, servindo como portfólio digital coletivo público.

## 💻 Como Executar Localmente

Como o projeto é construído exclusivamente com tecnologias web nativas (**HTML5**, **CSS3** e **JavaScript**), não é necessário instalar nenhum gerenciador de pacotes:

1. Clone o repositório:
   ```bash
   git clone https://github.com/whosmitri/workshop-devweb.git
   cd workshop-devweb
   ```

2. Abra o arquivo `index.html` em qualquer navegador moderno:
   - Dê dois cliques em `index.html`, ou
   - Utilize a extensão **Live Server** no VS Code para recarregamento em tempo real.
